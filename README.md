# Coflow Projesi

Coflow Teknoloji için geliştirilmiş bir frontend landing page projesi.  
İçerisinde smooth scroll navbar, şehir dropdown, form validasyonu ve testimonial slider bulunmaktadır.

# Özellikler
- Smooth scroll for navbar links
- City dropdown in contact form
- Form validation (frontend test)
- Testimonial slider with clickable dots
